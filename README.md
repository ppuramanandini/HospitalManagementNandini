We care for your heart. HospitalMan is a heart disease prediction and management system designed to provide world-class cardiology services in a soothing, patient-first environment. Your heart health is our mission, and this project aims to empower users and healthcare professionals to assess risk, track health data, and manage patient care efficiently through a web-based interface.

Built with Flask on the backend, and HTML, CSS, and JavaScript on the frontend, HospitalMan integrates a machine learning model for heart disease risk prediction. Users can input key health parameters such as age, BMI, smoking habits, and other vital signs, and the system generates a personalized prediction of heart disease risk, categorized as Low, Moderate, or High.

Beyond prediction, HospitalMan functions as a hospital management system. Users can book appointments with cardiologists, track patient data, and access emergency and routine checkup services. The system showcases various healthcare services including comprehensive heart checkups, advanced angioplasty procedures, diagnostic tools like ECG, Echo, and TMT, and 24/7 rapid emergency response for cardiac patients.

The project demonstrates a robust setup with impressive demo data: over 5,000 successful surgeries, 150+ expert doctors, 24/7 emergency care, and recognition as the #1 heart hospital in the region.

HospitalMan leverages a modern technology stack, combining Python and Flask for backend functionality, HTML/CSS/JavaScript for an interactive frontend, and Scikit-learn, Pandas, and NumPy for machine learning analytics. An optional SQLite database can store patient records securely, while Git and GitHub ensure version control and collaborative management.

This system provides a seamless experience for both patients and healthcare providers, allowing early risk detection, efficient appointment management, and quick access to critical services, all in a single, user-friendly platform.
