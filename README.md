Project Overview

HospitalMan is a heart disease prediction and management system.
It allows users and doctors to assess heart disease risk, track health data, and manage patient care efficiently using a web-based interface.

Built using Flask (backend)

Frontend: HTML/CSS/JS

Machine Learning: Heart Disease Risk Prediction Model

Key Features
Heart Health Prediction

Users enter age, BMI, smoking habits, and other parameters.

System predicts heart disease risk: Low, Moderate, High.

Hospital Management

Book appointments with cardiologists

Track patient data

Emergency and checkup management
